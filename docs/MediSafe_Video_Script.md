# MediSafe: "Vibe to Production in 180 Seconds" Video Script

Total length: 180 seconds, 23 clips. Gemini video generation is limited to 8 seconds per clip, so every AI-generated clip is 8 seconds or shorter. Where a clip is shorter than 8 seconds, generate 8 seconds and trim it in the editor.

| Segment | Time | Clips | Source |
|---|---|---|---|
| Problem (The Vibe) | 0:00-0:30 | 1-4 | Gemini |
| Solution | 0:30-1:00 | 5-8 | Gemini |
| Demo / Concept Flow | 1:00-2:00 | 9-15 | Real screen recording of the live site |
| AI Approach | 2:00-2:30 | 16-19 | Gemini |
| Impact and Next Step | 2:30-3:00 | 20-23 | Gemini |

## How to use this file

1. For every Gemini clip, copy the text under **Gemini prompt** into the video generation tool. Each prompt is self-contained and already includes the shared visual style.
2. Record the voiceover separately (your own voice or a text-to-speech tool) and lay it over the clip in your editor. Do not rely on Gemini to generate speech or on-screen text.
3. For the demo clips (9-15), do not use Gemini. Screen-record the real site at https://medisafe-portal.vercel.app so judges see the actual working prototype.

**Shared visual style (already included in every prompt below):** clean modern look, soft teal and white color palette, cinematic lighting, no text on screen, no logos.

Voiceover lines are written for roughly 18-20 words per 8 seconds. Read each one aloud once to check the timing.

## Notes before you record

- **Demo account:** log in with the demo account for the screen recordings. Any account you create for practice should be deleted afterwards.
- **KPIs are targets:** clip 21 describes what the team will measure, not results that have already been measured. Do not add numbers unless you have real data.
- **No RAG claim:** the AI approach is machine learning models, curated datasets and live medical APIs. The script does not claim retrieval-augmented generation because the project does not use it.
- **Bangla and localization:** the current interface is in English. The script shows localization through Bangladeshi brands, local pricing and Bangladesh-specific data, and lists Bangla language support as a next step.
- **Facts used:** about 21,700 medicine brands and 1,700 generics, 50,357 known interactions in the interaction dataset, Model 1 for interaction risk, Model 2 for alternatives and price comparison, live DailyMed and DDInter connections.
